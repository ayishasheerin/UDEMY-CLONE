# UDEMY-CLONE
Udemy clone website
🎓 Udemy Clone

A responsive Udemy Clone built using HTML. This project recreates the look and feel of an online learning platform, including course sections, navigation, categories, and responsive UI elements.

🚀 Live Demo

🔗 https://ayishasheerin.github.io/UDEMY-CLONE/

📌 Features

* 🎓 Udemy-inspired homepage design
* 📚 Course categories and course sections
* 🔍 Search bar and navigation menu
* 🎨 Clean and modern user interface
* 📱 Responsive design
* 🖼️ Course cards with images, titles, ratings, and pricing
* 📑 Footer section with useful links

🛠️ Technologies Used

* HTML5
* Flexbox
* CSS Grid
* Responsive Web Design

🎯 Purpose of the Project

This project was created for practice and learning purposes to improve my skills in:

* HTML structure
* CSS styling
* Flexbox and Grid
* Responsive layouts
* Creating real-world website interfaces
